# Airbnb: первое бронирование и действия пользователей Web-каналов

## Вопрос проекта

Чем различаются пользователи, пришедшие через каналы `content` и `direct`, по наличию первого бронирования и действиям в логах? Это описательный анализ исторических данных, а не оценка причинного эффекта маркетингового канала.

## Данные и рамки анализа

Источник: [Airbnb New User Bookings на Kaggle](https://www.kaggle.com/competitions/airbnb-recruiting-new-user-bookings/data), файлы `train_users_2.csv.zip` (пользователи и дата первого бронирования) и `sessions.csv.zip` (логи действий).

- Когорта: регистрация с января по июнь 2014 года включительно, `signup_app = Web`, `affiliate_channel` — `content` или `direct`.
- Основной показатель: доля пользователей с непустой `date_first_booking` среди пользователей соответствующей группы. Это доля с зафиксированным первым бронированием, а не конверсия за одинаковое число дней после регистрации.
- Анализ действий: только пользователи этой когорты, для которых доступны логи `sessions`. По каждому действию учитывается доля пользователей с хотя бы одной соответствующей записью, а не доля событий.
- Для двух страниц отчёта используются разные основания расчёта: все пользователи выбранной Web-когорты и её подмножество с логами. Проценты между страницами нельзя напрямую сравнивать как шаги одной воронки.

## Результаты

| Канал | Все пользователи Web | С первым бронированием | Доля с первым бронированием | Пользователи Web с логами | Просматривали результаты поиска | Обращались к хозяину |
|---|---:|---:|---:|---:|---:|---:|
| `content` | 1 642 | 182 | 11,08% | 1 630 | 65,58% | 6,56% |
| `direct` | 33 354 | 15 071 | 45,18% | 33 017 | 55,76% | 32,91% |

Общая доля с первым бронированием по двум каналам — **43,58%** (15 253 из 34 996). Она рассчитана по сумме пользователей и бронирований, а не как среднее двух процентов.

В когорте с логами просмотр результатов поиска чаще встречается у `content`, а обращение к хозяину — у `direct`. Действия не интерпретируются как последовательные стадии воронки: данные этого отчёта не устанавливают их порядок относительно бронирования.

## Ограничения

- Состав групп может различаться по другим признакам. Различия в долях нельзя приписывать влиянию канала без дополнительного дизайна исследования.
- Факт наличия первого бронирования не приведён к единому окну наблюдения после регистрации; сравнивать месяцы как сопоставимые когорты по скорости бронирования нельзя.
- Поведенческая часть ограничена пользователями с доступными логами; исключение пользователей без логов может менять состав сравниваемых групп.
- Данные исторические и не описывают текущую работу Airbnb.

## Как смотреть проект

1. Откройте сохранённый отчёт Power BI (`.pbix`) или экспорт двух страниц в PDF.
2. На странице «Первое бронирование — все Web» показаны помесячные доли по двум каналам и общий показатель.
3. На странице «Поведение пользователей с логами» сравниваются доли пользователей с отдельными действиями и указаны размеры групп.
4. Для воспроизведения вычислений загрузите исходные файлы самостоятельно со страницы соревнования на Kaggle и используйте ноутбук проекта. Не добавляйте исходные файлы Kaggle в публичный репозиторий без проверки правил соревнования.
