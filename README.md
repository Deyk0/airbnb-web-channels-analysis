# Airbnb: первое бронирование и действия пользователей Web-каналов

Личный исследовательский проект на исторических данных Airbnb. Цель — сравнить каналы `content` и `direct` по наличию первого бронирования и действиям пользователей. Это анализ наблюдаемых различий, а не оценка причинного эффекта маркетингового канала.

## Вопрос проекта

Чем различаются пользователи Web-каналов `content` и `direct` по доле первого бронирования? Какие действия чаще встречаются в подмножестве пользователей с логами? Сохраняется ли различие в доле первого бронирования среди пользователей с одинаковым способом регистрации `basic`?

## Данные и рамки анализа

Источник: [Airbnb New User Bookings на Kaggle](https://www.kaggle.com/competitions/airbnb-recruiting-new-user-bookings/data). Использованы `train_users_2.csv.zip` (пользователи и дата первого бронирования) и `sessions.csv.zip` (логи действий).

- Когорта: регистрация с января по июнь 2014 года включительно, `signup_app = Web`, `affiliate_channel` — `content` или `direct`.
- Основной показатель: доля пользователей с указанной `date_first_booking`. Это доля с зафиксированным первым бронированием, **не** конверсия за одинаковое число дней после регистрации.
- Анализ действий: только пользователи этой когорты, для которых доступны логи `sessions`. Для каждого действия учитывается доля пользователей с хотя бы одной соответствующей записью, а не доля событий.

У двух страниц отчёта **разные знаменатели**: все пользователи выбранной Web-когорты и её подмножество с логами. Проценты с разных страниц нельзя интерпретировать как шаги одной воронки.

## Результаты

| Канал | Все пользователи Web | С первым бронированием | Доля с первым бронированием |
|---|---:|---:|---:|
| `content` | 1 642 | 182 | 11,08% |
| `direct` | 33 354 | 15 071 | 45,18% |

Общая доля с первым бронированием по двум каналам — **43,58%** (15 253 из 34 996). Она рассчитана по сумме пользователей и бронирований, а не как среднее двух процентов.

Среди **Web-пользователей с логами**:

| Канал | Пользователи с логами | Просматривали результаты поиска | Обращались к хозяину |
|---|---:|---:|---:|
| `content` | 1 630 | 65,58% | 6,56% |
| `direct` | 33 017 | 55,76% | 32,91% |

В группе `content` просмотр результатов поиска встречается чаще, а обращение к хозяину — реже, чем в группе `direct`. Эти действия не считаются последовательными этапами: порядок событий в данном сравнении не проверялся.

## Проверка исследовательской гипотезы

Отдельно рассмотрены пользователи из той же Web-когорты со способом регистрации `signup_method = basic`.

- **H₀:** доли пользователей с первым бронированием в каналах `content` и `direct` равны.
- **H₁:** доли различаются.
- **Метод:** двусторонний z-тест двух пропорций при уровне значимости 0,05. Для разницы долей рассчитан 95% интервал методом Ньюкомба.

| Канал | Пользователи | С первым бронированием | Доля |
|---|---:|---:|---:|
| `content` | 940 | 129 | 13,72% |
| `direct` | 25 821 | 11 822 | 45,78% |

Разница `direct − content` составляет **32,06 процентного пункта**. Результат теста: **z = 19,42; p ≈ 5,005 × 10⁻⁸⁴**. Расчётный 95% интервал для разницы: **29,64–34,20 процентного пункта**.

При допущениях теста данные не согласуются с гипотезой о равенстве долей. В выбранной подгруппе не обнаружено бронирований с датой раньше регистрации. Во всех шести месяцах регистрации наблюдаемая доля у `direct` выше, чем у `content`; помесячные результаты использованы для описательной проверки, без шести отдельных тестов.

**Интерпретация:** это исследовательский, а не подтверждающий анализ — подгруппа `basic` выбрана после предварительного знакомства с данными. Пользователи не распределялись по каналам случайным образом. Результат не доказывает, что именно канал вызвал различие.

## Продуктовая гипотеза — не проверена

Возможная гипотеза для будущего эксперимента: более ясная информация об итоговой цене и условиях объявления вместе с заметной кнопкой связи с хозяином повысит долю первых бронирований среди новых Web-пользователей канала `content`.

Для её проверки потребовался бы A/B-тест со случайным распределением пользователей между текущим и изменённым интерфейсом и одинаковым заранее заданным окном наблюдения, например 30 дней после регистрации. Имеющиеся данные не проверяют эффект такого изменения.

## Ограничения

- Состав каналов может различаться по другим признакам; наблюдаемое различие нельзя приписывать влиянию канала без дополнительного дизайна исследования.
- Для показателя первого бронирования не задано одинаковое окно наблюдения после регистрации. Сравнивать месяцы как сопоставимые когорты по скорости бронирования нельзя.
- Анализ действий ограничен пользователями с логами; их состав может отличаться от полной Web-когорты.
- Исследовательская гипотеза сформулирована после изучения данных. p-value и расчётный интервал зависят от статистических допущений и не подтверждают причинность.
- В отдельных помесячных подгруппах `content` мало пользователей; например, среди регистраций `basic` в июне — 74.
- Данные исторические и не отражают текущие показатели Airbnb.
